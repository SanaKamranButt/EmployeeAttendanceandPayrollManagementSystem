# Employee Attendance & Payroll Management System

A Python-based Employee Attendance and Payroll Management System developed using Object-Oriented Programming (OOP). The application allows administrators to manage employees, record attendance, calculate salaries, and generate payroll reports.

## Features

- Admin Login
- Employee Login
- Add Employees
- View Employees
- Search Employees
- Employee Attendance (Check-In / Check-Out)
- Attendance History
- Salary Calculation
- Overtime Calculation
- Monthly Payroll Report
- Export Payroll to CSV
- Export Payroll to PDF
- JSON File Storage
- Exception Handling

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- ReportLab
- CSV

## Project Structure

```
main.py
attendance.py
payroll.py
report.py
employees.json

```
